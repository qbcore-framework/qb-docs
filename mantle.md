# Mantle and QBCore

[Mantle](https://mantleplatform.com/) is a platform built with Unreal Engine 5 where creators can build and publish multiplayer worlds for players to join. Creators use the free Mantle Core editor plugin to check and publish their worlds. The Mantle PC app is currently in closed testing on Steam and the Epic Games Store.

## Where QBCore fits in

QBCore is the open source flagship roleplay framework for Mantle. A new implementation is being developed privately, and a public repository is planned. QBCore has withdrawn from other platforms.

The existing guides and reference pages in these docs cover the previous QBCore implementation. They remain here as a reference while work on the Mantle implementation continues.

Join the [Mantle Discord](https://discord.gg/mantlegame) to follow along and meet the community.
